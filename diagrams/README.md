# Diagrams

This directory is reserved for the visual layer of the Production-Ready Azure Data Pipeline.

The standardization pass will use it for a small, focused visual package rather than decorative screenshots.

Planned visual roles:

- README hero / cover
- end-to-end architecture
- security and identity flow
- monitoring and alerting flow

Visual standard:

- dark navy / near-black base;
- cyan / teal Azure-oriented accents;
- minimal visual noise;
- one engineering idea per diagram;
- consistent family resemblance with the other Azure portfolio repositories.

The diagrams must explain implemented behavior only and must not introduce capabilities that were not part of the MVP.
