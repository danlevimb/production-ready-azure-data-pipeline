# Companion Dojo Decision

**Project:** `production-ready-azure-data-pipeline`

---

## 1. Purpose

This document evaluates whether a private companion dojo should be created for the production-ready project.

The roadmap rule says:

```text
Every public portfolio project should have a companion private dojo / learning lab when hands-on reinforcement is valuable.
```

---

## 2. Recommendation

A companion dojo is useful, but it does not need to start immediately unless deeper practice is desired.

Recommended decision:

```text
Defer the companion dojo until after final project closeout and roadmap update.
```

Rationale:

The public project itself already provided strong hands-on practice across Bicep, ADF, ADLS, RBAC, Key Vault, Log Analytics, KQL, and alerting.

---

## 3. Possible Future Dojo Name

Recommended name:

```text
azure-production-readiness-learning-lab
```

---
