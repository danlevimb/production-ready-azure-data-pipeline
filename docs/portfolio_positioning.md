## 4. Interview Explanation

```text
After building functional Azure data engineering projects, I wanted to demonstrate production readiness. I created a small ADF pipeline that ingests retail CSV files into ADLS Gen2, but the focus was not the data volume. The focus was operational maturity: infrastructure defined with Bicep, secure access with Managed Identity and Key Vault, GitHub Actions validation, pipeline run traceability, Log Analytics monitoring, KQL diagnostics, controlled failure testing, and an Azure Monitor alert rule that notified me by SMS and email when the pipeline failed.
```

## 5. Honest Boundary Statement

```text
This is a portfolio-ready MVP, not a full enterprise production platform. It intentionally excludes private endpoints, full CI/CD deployment automation, multi-environment promotion, Purview governance, and complex data transformations. Those are documented as future improvements.
```
